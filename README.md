### How to Install Blueprints

**Step 1 – Download a Blueprint**

1. Browse the collection and choose a building.
2. Open its GitHub page.
3. Click on the `.cpbp` file.
4. Click the download icon to save the file.

**Step 2 – Open the Game Directory**

1. Open your Steam Library.
2. Right-click **Car Park Capital**.
3. Select **Manage → Browse local files**.
4. Open the `assets` folder and then the `blueprints` folder.

**Step 3 – Install the Blueprint**

Inside the `blueprints` folder, you will find three parking garage folders:

- `small_parking_garages`
- `medium_parking_garages`
- `large_parking_garages`

Copy the downloaded `.cpbp` file into the appropriate parking garage folder.

For example:

`assets\blueprints\small_parking_garages\Office_Parking_1.cpbp`

**Step 4 – Start the Game**

1. Close Car Park Capital completely if it is running.
2. Restart the game.
3. Open the corresponding parking garage category.
4. Select and place your new building!

No mods or additional software required!

**Important:** Game updates may affect custom blueprint files. Keep a backup of your downloaded blueprints.

### Blueprints installieren

**Schritt 1 – Blueprint herunterladen**

1. Durchsuche die Sammlung und wähle ein Gebäude aus.
2. Öffne die entsprechende Gebäudeseite auf GitHub.
3. Klicke auf die `.cpbp`-Datei.
4. Lade die Datei über das Download-Symbol herunter.

**Schritt 2 – Spielverzeichnis öffnen**

1. Öffne deine **Steam-Bibliothek**.
2. Klicke mit der rechten Maustaste auf **Car Park Capital**.
3. Wähle **Verwalten → Lokale Dateien durchsuchen**.
4. Öffne den Ordner `assets` und anschließend den Ordner `blueprints`.

**Schritt 3 – Blueprint installieren**

Im Ordner `blueprints` findest du drei Ordner für Parkhäuser:

- `small_parking_garages` – Kleine Parkhäuser
- `medium_parking_garages` – Mittlere Parkhäuser
- `large_parking_garages` – Große Parkhäuser

Kopiere die heruntergeladene `.cpbp`-Datei in den passenden Parkhaus-Ordner.

**Beispiel:**

`assets\blueprints\small_parking_garages\Office_Parking_1.cpbp`

**Schritt 4 – Spiel starten**

1. Falls Car Park Capital noch läuft, beende das Spiel vollständig.
2. Starte das Spiel erneut.
3. Öffne die entsprechende Parkhaus-Kategorie.
4. Wähle dein neues Gebäude aus und platziere es!

Fertig! Keine Mods oder zusätzliche Programme erforderlich!

**Wichtig:** Spielupdates können sich auf eigene Blueprint-Dateien auswirken. Bewahre deshalb am besten eine Sicherung deiner heruntergeladenen Blueprints auf.
